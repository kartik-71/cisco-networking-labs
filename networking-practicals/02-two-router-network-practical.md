## What We Learned

In this practical we learned about the working and setup of Cisco Packet Tracer. We learned about wires, switches and connections.

We also learned:
- How to ping from one PC to another PC.
- How IP addresses are connected within the network.
- How to use PDU in Packet Tracer.
- How to check routing information using `show ip route`.
- How to check interface and IP status using `show ip interface brief`.
